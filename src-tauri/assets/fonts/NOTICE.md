# Bundled Fonts

These fonts are bundled into the xmark binary to render text watermarks and
the on-canvas Live Preview, and are all licensed under the SIL Open Font
License 1.1 (OFL), sourced from the Google Fonts repository
(https://github.com/google/fonts):

- Inter — https://github.com/google/fonts/tree/main/ofl/inter
- Roboto — https://github.com/google/fonts/tree/main/ofl/roboto
- Roboto Mono — https://github.com/google/fonts/tree/main/ofl/robotomono
- Arvo — https://github.com/google/fonts/tree/main/ofl/arvo
- Pacifico — https://github.com/google/fonts/tree/main/ofl/pacifico
